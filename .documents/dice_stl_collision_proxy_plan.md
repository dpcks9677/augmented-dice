# STL 트레이 충돌 프록시 정합 계획서

- 작성일: 2026-07-30
- 상태: 구현 및 좌표 검증 완료
- 범위: `YachtTrayModel`, `DiceBoardPhysics`, `DiceEngine`
- 비범위: 게임 규칙, 주사위 결과 판정, 네트워크 메시지, STL 원본 수정

## 1. 문제와 목표

현재 물리판은 중앙 바닥 높이 `Y=-10.283531`의 평면 Box이다. 중앙 바닥(X `-50..50`)에서는 STL과 일치하지만, 좌우와 전면의 구덩이 경사면에서는 STL보다 낮다.

| 위치 | STL 상면 Y | 물리판 대비 |
| --- | ---: | ---: |
| X=50, Z=0 | -10.283531 | 0 |
| X=52, Z=0 | 4.425351 | +14.708882 |
| X=58, Z=0 | 15.000000 | +25.283531 |
| X=0, Z=55 | 9.961163 | +20.244694 |

목표는 주사위가 보이는 STL 바닥·경사면·림과 같은 위치에서 충돌하도록 만드는 것이다. 충돌은 단순하고 안정적이어야 하며, 기존 6시 방향 진입과 결과 동기화는 유지한다.

## 2. 해결안

STL 전체를 Cannon `Trimesh`로 쓰지 않는다. 고속 주사위와 오목 STL의 삼각형 충돌은 비용과 튐 현상을 키운다.

대신 STL에서 측정한 단면으로 다음 정적 Box 프록시를 구성한다.

1. 중앙 평면: 실제 평평한 바닥 영역만 지원한다.
2. 좌·우 경사판: 중앙 바닥 끝에서 좌·우 림 상단까지 기울어진 얇은 Box를 배치한다.
3. 전면 경사판: Z축 전면 경사면을 같은 방식으로 배치한다. 후면은 킵 포켓과 맞닿는 기존 경계(`Z=-35`)를 유지한다.
4. 림 벽: 각 경사판의 상단 끝에서만 수직 벽을 시작한다.
5. 진입판: `INGRESS`에서만 기존처럼 6시 바깥까지 평면을 연장한다. 트레이 내부 프록시는 제거하지 않는다.

이 구조에서는 주사위가 중앙에서 경사면으로 자연스럽게 올라가고, 림에서 멈춘다. 평면 물리판이 STL 경사면 아래를 통과하는 문제도 제거된다.

## 3. 좌표 계약

`YachtTrayModel`이 STL에 적용한 변환과 동일한 좌표계에서 레이캐스트로 단면을 측정한다. `getLayout()`은 화면 배율이 적용된 다음 값을 제공한다.

```js
collisionProfile: {
  center: { minX, maxX, minZ, maxZ, y },
  ramps: {
    left:  { inner, outer, innerY, outerY },
    right: { inner, outer, innerY, outerY },
    back:  { inner, outer, innerY, outerY },
    front: { inner, outer, innerY, outerY }
  },
  rim: { leftX, rightX, backZ, frontZ, leftY, rightY, backY, frontY }
}
```

- 측정 기준점은 각 변 중앙이다. 예: 좌·우는 `Z=0`, 앞·뒤는 `X=0`.
- 중앙 평면 끝과 림 상단은 높이 변화가 시작·종료되는 지점으로 찾는다.
- STL 로딩 실패 시 현재의 평면 `playBounds`를 안전한 폴백으로 사용한다.
- `rollBounds`는 제거하고 `collisionProfile`만 물리 경계의 기준으로 사용한다. 색상용 `PLAY_BOUNDS`는 유지한다.

## 4. 구현 순서

1. `YachtTrayModel`
   - 기존 `getSurfacePoint()`를 재사용해 중앙·경사 시작·림 상단을 측정한다.
   - 원본 단위의 폴백 프로필을 함께 둔다.
   - `getLayout()`에서 모든 프로필 값을 현재 `scale`로 변환한다.

2. `DiceBoardPhysics`
   - 단일 평면 `floorBody`를 중앙 평면 Box와 3개의 경사 Box로 교체한다.
   - 경사 Box는 두 끝점의 높이 차로 회전각을 계산하고, 상면이 STL 단면을 따르도록 두께만 아래쪽으로 둔다.
   - 벽의 하단 Y를 중앙 바닥이 아니라 해당 림 상단 Y로 올린다.
   - `NORMAL`, `INGRESS`, `FLIP` 모두 같은 내부 프록시를 공유한다. `INGRESS`는 외부 진입판·가이드만 추가한다.

3. `DiceEngine`
   - `currentFloorY`와 착지 높이는 중앙 평면 Y를 계속 사용한다.
   - 진입 중 림을 넘는 초기 속도 계산은 `rimTopY`와 새 프로필의 전면 림 Y 중 큰 값을 사용한다.
   - 결과 값과 `spawnTransforms` 형식은 변경하지 않는다.

## 5. 검증

자동 검증:

- 중앙 평면·각 경사판·림 벽의 상면/내측면이 레이캐스트 측정값과 허용오차 `0.05` 이내인지 검사한다.
- D6, 중량 D6, D8의 일반 5개·혼합 6개·단일 1개 굴림을 각 100회 실행한다.
- 보드 이탈, STL 관통, 바닥 아래 추락, 충돌체 미정리 0회를 확인한다.

수동 검증:

- 좌우·앞뒤 림으로 굴린 주사위가 STL 경사면 위를 따라 움직이는지 확인한다.
- 6시 진입 중 림 관통 없이 내부로 들어오는지 확인한다.
- 창 크기 변경 후에도 STL과 프록시가 함께 배율 변경되는지 확인한다.
- 호스트와 참가자의 최종 결과·정렬이 기존과 동일한지 확인한다.

## 6. 완료 기준

- 중앙 바닥, 좌우·전면 경사, 림 벽의 충돌 위치가 STL 표면과 일치한다.
- 투명 평면이나 수직 벽이 STL 내부에서 먼저 주사위를 막지 않는다.
- 기존 물리 안정성 및 멀티플레이 결과 동기화가 회귀하지 않는다.

## 7. 구현 결과

- `YachtTrayModel`이 변환된 STL에서 중앙 바닥·좌우 림·전면 림 높이를 측정해 `collisionProfile`을 제공한다.
- `DiceBoardPhysics`가 중앙 바닥, 좌우/전면 경사판, 림 높이부터 시작하는 벽을 생성한다.
- 상면 좌표와 림 내측면 자동 검증, 동적 구체 접촉 검증, 프로덕션 빌드를 통과했다.
