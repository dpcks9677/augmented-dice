# 주사위 그림자 교체 전환 계획

## 목표

- 롤 중 연한 전용 보조 그림자를 유지함.
- 정렬 진행에 맞춰 연한 그림자를 fade out 함.
- 같은 진행률로 진한 보조 그림자를 fade in 함.

## 구현 방법

- 롤 중에는 광원 그림자 대신 60% 불투명도의 전용 보조 그림자를 주사위 위치에 표시함.
- 롤 그림자의 평면 회전을 주사위 quaternion의 지면 투영 축에 맞춰, 주사위 회전 방향을 따라가게 함.
- 주사위 중심이 플레이 영역 밖에 있는 진입 구간에는 롤 그림자를 숨겨 6시 경계 clamp 잔상을 막음.
- 정렬 중 `animationProgress`에 따라 롤 그림자를 fade out하고 정렬 그림자를 fade in 함.
- 실제 광원 세기는 변경하지 않아 게임 보드 전체 밝기를 유지함.

## 검증

- 빌드·구조 테스트·diff 검사를 실행함.
- 그림자 회전 계산과 플레이 영역 판정을 단위 테스트함.

## 구현 결과

- 롤 그림자가 주사위 지면 투영 회전을 따라가도록 수정함.
- 플레이 영역 밖 6시 진입 구간의 롤 그림자를 숨기도록 수정함.
- 전용 단위 테스트, 메인 구조 테스트, 구문 검사, 프로덕션 빌드, diff 검사를 통과함.
- 실제 롤 화면에서 최종 시각 확인 필요함.
