## 확정 규칙

- 결투는 2인 증강 모드만 고려함. 상대 기권으로 게임이 끝나면 미결정 상태로 종료함.
- 코인 토스의 상단 보너스 기준 감소는 보유자에게만 적용함.
- 랜덤 박스는 자신·보유 중·충돌·퀘스트·비활성 증강을 제외함. 변형 당첨 시 기존 변형 슬롯을 덮어씀.
- 예지 숫자는 실제 빈 족보에서 가능한 점수 중 1~30만 제시함.
- 갬빗의 4개/6개 주사위는 모두 일반 주사위로 구성함.
- 더블 다운은 9턴부터 사용 가능함. 추진력과 함께 발동하면 합연산 2배를 적용함.
- 저금통은 남은 리롤당 3점을 적립하고 12점 도달 시 12점을 지급한 뒤 비움.
- 주사위 연금술은 첫 굴림 후 킵하지 않은 주사위만 최소 1까지 1 감소함.

## 구현 구조

- UI 데이터와 슬롯 정의를 `augments.json`, `scoreEngine.js`에 추가함.
- 온라인 결과와 액션 검증은 `authoritativeGame.js`에서 결정함.
- 서버는 `game_augment_action`만 받아 권위 상태를 갱신함.
- 핫시트는 같은 규칙의 로컬 상태와 액션 버튼을 사용함.
- 전역 증강 보너스는 퀘스트 보너스와 분리해 합계·승패·전적에 반영함.
- 랜덤 박스의 추가 증강은 정규 드래프트 횟수에 포함하지 않음.

## 검증

- 코인 토스 4개 결과, 갬빗 4→6 전환, 더블 다운·추진력 2배, 저금통 인출, 결투, 예지자를 단위 테스트함.
- 권위 서버 회귀 테스트와 Vite 프로덕션 빌드를 통과함.
- 로얄 다이스와 소원의 요정은 데이터·슬롯·로직 모두 추가하지 않음.
