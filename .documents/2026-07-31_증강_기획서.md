본 문서는 요트 다이스 게임 내에 새롭게 추가될 신규 증강 5종(결투, 코인 토스, 랜덤 박스, 예지자, 갬빗)의 상세 기능 정의 및 최종 결정사항을 반영한 기획서입니다. 특히 예지자 증강의 코드베이스 실행안과 스마트 필터링 매커니즘을 구체적으로 다룹니다.

## ⚔️ 1. 결투 (Duel)
*   **분류:** 강화 (Enhancement)
*   **기획 명세:**
    *   증강을 획득한 턴에 즉시 상대와 결투를 벌입니다.
    *   이번 라운드(획득한 턴)에서 등록한 족보의 최종 점수가 상대방보다 높은 플레이어가 승리합니다.
    *   **승리 보상:** 승리한 플레이어에게는 **보너스 10점**이 즉시 부여되며, 이 점수는 최종 점수판의 `total` 칸에 즉시 합산되어 반영됩니다.
    *   **동점 처리 (최종 결정):** 결투 결과가 동점일 경우, **증강 보유자에게만 보너스 +5점**을 부여합니다. (상대는 0점) 이를 통해 증강 획득 턴에 무승부가 나더라도 증강 보유자의 이점과 최소한의 리턴을 보장합니다.

## 🪙 2. 코인 토스 (Coin Toss)
*   **분류:** 강화 (Enhancement)
*   **기획 명세:**
    *   게임 당 단 1회, 코인 토스에 도전할 수 있는 기회를 얻습니다.
    *   증강 박스 내부에 **"코인 토스!"** 액션 버튼이 배치됩니다.
    *   버튼을 누르면 3개의 동전이 동시에 던져지는 애니메이션이 출력되며, 앞면의 개수에 따라 아래의 효과가 즉시 발동합니다.
    *   **결과별 효과:**
        *   **앞면 0개:** -5점의 페널티를 즉시 total 점수에 반영합니다.
        *   **앞면 1개:** 현재 굴려진 주사위 중 가장 낮은 눈의 주사위 하나의 면을 즉시 **6**으로 변경합니다.
        *   **앞면 2개:** 이번 턴에 리롤(재굴림) 기회를 추가로 +1회 더 획득합니다.
        *   **앞면 3개:** 이번 게임 전체에서, 상단 보너스 획득 조건(기본 63점)을 **6점 낮춰 57점**으로 영구 완화합니다.
    *   **UI/UX 상호작용 및 예외 처리:**
        *   **버튼 활성화 조건:** 주사위를 한 번 이상 굴린 후에만 버튼이 활성화됩니다.
        *   **미굴림 상태 터치 시:** "주사위를 먼저 굴리세요!" 경고 메시지를 출력하며 버튼이 좌우로 흔들리는(Shake) 연출을 수행합니다.
        *   **이미 사용한 상태 터치 시:** "기회는 단 한 번 뿐입니다." 경고 메시지를 출력하며 동일하게 흔들림 연출을 수행합니다.

## 🎁 3. 랜덤 박스 (Random Box)
*   **분류:** 강화 (Enhancement)
*   **기획 명세 (최종 결정):**
    *   획득 즉시, **퀘스트 분류를 제외한** 무작위 증강(변형 또는 강화)을 하나 무작위로 획득합니다.
    *   동시에 이번 게임 전체에서 상단 보너스 획득 조건을 **5점 낮춰 58점**으로 완화합니다.
    *   **디자인 의도:** 변형 증강 획득 시 기존에 기획해 둔 빌드가 손상될 수 있는 하이 리스크가 존재합니다. 그러나 플레이어는 이 리스크를 감수하고 행운을 바라는 목적으로 랜덤 박스를 선택하는 것이므로, 필터링 없이 **기존 기획대로 변형 및 강화 증강 전체 풀에서 무작위 획득**하도록 유지합니다.

## 🔮 4. 예지자 (Prophet)
*   **분류:** 퀘스트 (Quest)
*   **기획 명세 (최종 결정):**
    *   증강 획득 시점부터 **3턴 동안** 퀘스트가 활성화됩니다.
    *   매 턴 시작 시, 예지자가 $1$에서 $30$ 사이의 무작위 숫자 3개를 제시합니다. (예: `[12, 18, 25]`)
    *   해당 턴에 족보 칸에 기입한 최종 점수가 제시된 3개의 숫자 중 **하나와 정확히 동일할 경우, 그 턴에 즉시 보너스 7점**을 획득합니다.
    *   **메커니즘:** 3턴 동안 매 턴마다 개별적으로 점수 판정이 이루어집니다. 따라서 플레이어는 3턴 동안 최대 3번 성공하여 **최대 21점**의 보너스 점수를 획득할 수 있습니다.
    *   **퀘스트 진행도 텍스트:**
        *   `퀘스트: 3턴 동안 예지자가 제시한 숫자와 동일한 점수로 족보에 기입하세요. (n턴 남음!)` (n은 3, 2, 1로 매 턴 감소)

### 💻 코드베이스 구체적 실행안 및 구현 방식
예지자 증강이 제시하는 3개의 숫자가 완전히 불가능한 값이 되어 플레이어에게 불쾌감을 주는 것을 막기 위해 **스마트 필터링(Smart Filtering) 메커니즘**을 도입합니다.

#### 1. 대상 족보 분석
매 턴 시작 시, 플레이어의 **현재 비어있는 족보(Scoreboard) 슬롯**을 파악합니다.
*   **상단 구역 (Aces ~ Sixes):** 주사위 5개 중 해당 눈금의 개수($0 \sim 5$개)에 따른 점수 후보군.
    *   *Aces:* [0, 1, 2, 3, 4, 5]
    *   *Deuces:* [0, 2, 4, 6, 8, 10]
    *   *Threes:* [0, 3, 6, 9, 12, 15]
    *   *Fours:* [0, 4, 8, 12, 16, 20]
    *   *Fives:* [0, 5, 10, 15, 20, 25]
    *   *Sixes:* [0, 6, 12, 18, 24, 30]
*   **하단 구역 및 변형 족보:**
    *   *Choice:* 주사위 5개 눈금 총합 후보군 ($5 \sim 30$)
    *   *4 of a Kind / 3 of a Kind / 4x4:* 눈금 총합 후보군 ($5 \sim 30$) 및 실패 시 0점
    *   *Full House / Tiny House / Two Pair / Head & Run:* 족보 정의 점수 (예: 28, 15 등) 또는 눈금 총합 연계 점수
    *   *Small / Large Straight:* 15, 30, 40 또는 0점
    *   *Yacht / Blackjack / 피보나치:* 50, 21, 25, 0점 등

#### 2. 스마트 필터링 알고리즘 로직
예지자는 매 턴 플레이어의 빈 족보 슬롯을 스캔하여 **실제로 기입 가능한 점수 후보군(Score Candidate Pool)**을 동적으로 생성한 후, 그 안에서 3개의 숫자를 무작위로 추출하여 제시합니다.

```javascript
// 예지자 스마트 필터링 구현 의사코드 (Client-side / src/scoreEngine.js 연계)
function generateProphetNumbers(playerScoreboard, activeMutations) {
  const candidateSet = new Set();
  
  // 1. 현재 비어있는 족보 슬롯 필터링
  const emptySlots = Object.keys(playerScoreboard).filter(slot => playerScoreboard[slot] === null);
  
  emptySlots.forEach(slot => {
    // 2. 각 슬롯별 이론상 획득 가능한 대표 점수 조합 추가
    switch(slot) {
      case 'aces':   [1, 2, 3, 4, 5].forEach(v => candidateSet.add(v)); break;
      case 'deuces': [2, 4, 6, 8, 10].forEach(v => candidateSet.add(v)); break;
      case 'threes': [3, 6, 9, 12, 15].forEach(v => candidateSet.add(v)); break;
      case 'fours':  [4, 8, 12, 16, 20].forEach(v => candidateSet.add(v)); break;
      case 'fives':  [5, 10, 15, 20, 25].forEach(v => candidateSet.add(v)); break;
      case 'sixes':  [6, 12, 18, 24, 30].forEach(v => candidateSet.add(v)); break;
      
      case 'choice':
        // Choice는 현실적으로 나올 확률이 높은 총합 범위(12~24) 위주로 추가
        for(let i = 12; i <= 24; i++) candidateSet.add(i);
        break;
        
      case 'fullhouse':
        candidateSet.add(15); // 투 페어 등 변형 고려
        candidateSet.add(28); // 타이니 하우스 등 변형 고려
        // 일반 풀하우스 점수 후보군 (10~28 사이)
        [10, 13, 16, 17, 19, 21, 22, 23, 24, 26, 27, 28].forEach(v => candidateSet.add(v));
        break;
        
      case 's-straight':
        candidateSet.add(15);
        candidateSet.add(20); // Odds/Evens 변형
        break;
        
      case 'l-straight':
        candidateSet.add(30);
        candidateSet.add(35); // Prime Collection/Duplex
        candidateSet.add(40); // Mountain
        break;
        
      case 'yacht':
        candidateSet.add(50);
        candidateSet.add(21); // Blackjack 변형
        candidateSet.add(25); // 피보나치 변형
        break;
    }
  });

  // 3. 0점(스크래치)은 예지 대상에서 제외 (도전 과제 가치 훼손 방지)
  candidateSet.delete(0);

  // 4. 후보군 배열 변환
  const candidates = Array.from(candidateSet);
  
  // 만약 빈 슬롯이 적어 후보군이 3개 미만인 경우, 1~30 사이의 기본 점수로 채움
  while(candidates.length < 3) {
    const fallback = Math.floor(Math.random() * 30) + 1;
    if(!candidates.includes(fallback)) candidates.push(fallback);
  }

  // 5. 무작위 3개 숫자 셔플 후 반환
  return candidates.sort(() => 0.5 - Math.random()).slice(0, 3);
}
```

#### 3. 점수 기입 검증 및 보상 지급 흐름
1. **턴 시작 시:** `generateProphetNumbers()`를 실행하여 `prophetNumbers: [X, Y, Z]`를 생성하고 UI에 표시.
2. **플레이어가 족보 기입 액션 시 (`scoreEngine.js` 계산 이후):** 
   * 기입하려는 점수가 `prophetNumbers` 중 하나와 일치하는지 검사.
   * 일치 시, 해당 턴 획득 점수와 별개로 **보너스 점수 7점**을 추가 연산하여 `total` 점수 및 데이터베이스에 즉시 반영.
   * `UI 이펙트(반짝임 등)`와 함께 보너스 획득 연출 출력.
3. **턴 종료 시:** 예지자 턴 카운트(`n턴 남음!`)를 1 감소시키고, 3턴이 종료되면 예지자 퀘스트 UI를 제거하는 것이 아니라 기존 퀘스트 증강과 동일하게 **취소선(strike-through) 처리**하여 비활성화 상태를 유지합니다.

## 🎯 5. 갬빗 (Gambit)
*   **분류:** 강화 (Enhancement)
*   **기획 명세:**
    *   게임 당 단 1회, 플레이어가 원하는 타이밍에 갬빗을 시도할 수 있습니다.
    *   증강 박스 내부에 **"갬빗 시도!"** 액션 버튼이 배치됩니다.
    *   **발동 메커니즘:**
        *   **발동 턴(페널티):** 주사위를 **4개**만 가지고 턴을 진행합니다.
        *   **다음 턴(메리트):** 주사위를 **6개**를 가지고 턴을 진행합니다.
    *   **UI/UX 상호작용 및 예외 처리:**
        *   **발동 중 터치 시:** "갬빗을 시도 중입니다!" 경고 멘트를 출력하며 흔들림 연출을 적용합니다.
        *   **사용 완료 후 터치 시:** "무리수는 한 번으로 족해." 경고 멘트를 출력하며 흔들림 연출을 적용합니다.
