# 주사위 그림자 강화 구현 계획

## 목표

- 보드 위 주사위 그림자를 식별 가능하게 유지함.
- 정렬 완료 후에도 그림자가 숨겨지지 않게 함.

## 구현 방법

- 정렬 주사위의 `castShadow`를 끄고 바닥의 전용 보조 그림자를 사용함.
- 정렬 그림자 갱신은 물리 투척 중인지 기준으로 판단함.
- 기존 캔버스 그림자 대비와 커스텀 그림자 불투명도만 강화함.

## 검증

- 정렬 전·중·후 그림자 표시 확인 필요함.
- 빌드·구조 테스트·diff 검사 실행함.

## 구현 결과

- 롤·정렬 상태별 전용 보조 그림자 표시를 적용함.
- 정렬 완료 후에도 활성 주사위 그림자가 유지되도록 수정함.
