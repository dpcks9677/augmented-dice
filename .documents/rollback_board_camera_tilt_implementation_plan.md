# 보드 카메라·주사위 틸팅 롤백 계획

## 목표

- 보드 카메라를 수평 0도로 복원함.
- 정렬·킵 주사위를 카메라와 수평인 기본 quaternion으로 표시함.
- 12도 전용 정렬 보정값과 위치 오프셋을 제거함.

## 구현 방법

- `DiceEngine`의 카메라 기울기 상수를 0도로 설정함.
- 기존 수평 뷰 정렬값(`cameraLift: 30`, `spacing: 2.65`, `centerZOffset: 0`)으로 복원함.
- 정렬 및 킵 주사위 quaternion에 추가 X축 틸트를 적용하지 않음.

## 검증

- 빌드·구조 테스트·diff 검사를 실행함.
