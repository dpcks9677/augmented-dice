# 프리셋 스튜디오 모델 뷰어·동전 시뮬레이션 통합 계획

## 1. 목표

- 기존 `preset-studio.html`과 `viewer.html` 기능을 하나의 프리셋 스튜디오로 통합함.
- 주사위, 동전, 보드 등 프로젝트 내 3D 모델을 선택해 회전·확대·이동하며 확인할 수 있게 함.
- 선택한 주사위 모델을 실제 보드 안에서 한 번 던져보는 시뮬레이션을 제공함.
- 동전은 보드 중앙에서 수직으로 회전하고 착지 즉시 바닥에 붙는 연출을 제공함.
- 기존 프리셋 추출·저장 프리셋 리뷰·팩 내보내기 기능을 유지함.

## 2. 현재 구조

- `preset-studio.html` + `src/presetStudio.js`
  - Yacht 보드 씬, 프리셋 베이킹, 저장 프리셋 불러오기, 재생, 확정, 내보내기를 담당함.
- `viewer.html` + `src/viewer.js`
  - 주사위 종류별 단일 모델 뷰를 담당함.
- `src/presetBaker.js`
  - Cannon 기반 주사위 투척·판 뒤집기 프레임을 생성함.
- `src/CoinModel.js`
  - 동전 지오메트리·재질·메시·앞뒷면 판정을 제공함.
- `src/DiceBoardPhysics.js`
  - 주사위 투척 및 프리셋 베이킹용 보드 충돌 구조를 제공함.

## 3. 통합 방식

### 3.1 단일 페이지

- `preset-studio.html`을 통합 진입점으로 유지함.
- 좌측 패널을 다음 영역으로 구성함.
  1. 모델 뷰어
  2. 판 시뮬레이션
  3. 프리셋 추출
  4. 저장 프리셋 리뷰·내보내기
- `viewer.html`은 통합 완료 후 프리셋 스튜디오로 이동시키는 안내 페이지 또는 제거 후보로 둠.

### 3.2 모델 레지스트리

- `presetStudio.js` 안에 최소 데이터 레지스트리를 둠.
- 각 항목은 `id`, 표시명, 모델 생성 함수, 기본 카메라 구도를 가짐.
- 초기 모델 목록:
  - 일반 6면체
  - 황금 주사위
  - 세븐스 다이스
  - 커플 주사위
  - 프로모션 주사위
  - 이상한 주사위
  - 묵직한 주사위
  - 8면 주사위
  - 동전
  - Yacht 보드
- 기존 `geometryUtils.js`, `diceMaterials.js`, `CoinModel.js`, `YachtTrayModel.js`를 그대로 재사용함.

### 3.3 화면 모드

- `inspect` 모드
  - 선택 모델 하나를 씬 중앙에 표시함.
  - OrbitControls로 회전·확대·이동함.
  - 보드는 필요할 때만 표시함.
- `simulate` 모드
  - Yacht 보드와 선택 오브젝트를 표시함.
  - 주사위는 `PresetBaker.bakeSingle()` 결과를 즉시 재생함.
  - 동전은 전용 수직 뒤집기 애니메이션을 재생함.
- 모드 전환 시 이전 메시·애니메이션 상태를 정리해 중복 렌더링을 막음.

## 4. 동전 뒤집기 메커니즘

- 동전 중심의 `x`, `z`는 보드 중앙에 고정함.
- `y`는 포물선으로 계산함.
  - 상승 → 정점 → 수직 하강
- 회전은 로컬 X축 또는 Z축 한 축만 사용함.
  - 불필요한 좌우 흔들림을 제거함.
  - 목표 면에 맞춰 정수 또는 반정수 회전 수를 선택함.
- 착지 마지막 구간에서 easing을 적용함.
- 착지 시 위치를 `playSurfaceY + thickness / 2`로 고정함.
- 쿼터니언을 정확한 앞면 또는 뒷면 방향으로 스냅함.
- 충돌 후 튀기거나 굴러가는 Cannon 물리는 사용하지 않음.
  - 요청한 깔끔한 수직 스핀과 즉시 밀착 연출을 우선함.
- 결과는 `getCoinSideFromQuaternion()`으로 확인해 UI에 표시함.

## 5. 주사위 판 시뮬레이션

- 선택한 주사위 타입과 개수로 `PresetBaker.bakeSingle()`을 1회 실행함.
- 생성된 프레임을 기존 `playPreset()` 경로로 재생함.
- 6면체와 8면체는 기존 보드 충돌·투척 규칙을 그대로 재사용함.
- 프리셋 대량 추출과 단발 시뮬레이션은 동일한 Baker를 사용해 결과 차이를 줄임.

## 6. UI 원칙

- 기존 프리셋 스튜디오의 어두운 패널, 금색 강조색, 버튼 스타일을 유지함.
- 기능을 새 페이지로 분산하지 않고 한 패널 안에서 구획함.
- 모델 선택과 실행 버튼을 분리함.
- 현재 모드, 선택 모델, 동전 결과, 시뮬레이션 상태를 텍스트로 표시함.
- 작은 화면에서는 패널 폭을 줄이고 스크롤 가능하게 유지함.

## 7. 예상 변경 파일

- `preset-studio.html`
  - 통합 모델 뷰어와 시뮬레이션 컨트롤 추가함.
- `src/presetStudio.js`
  - 모델 레지스트리, inspect/simulate 모드, 단발 주사위 투척, 동전 뒤집기 추가함.
- `src/CoinModel.js`
  - 필요 시 재질 그룹 또는 리소스 정리 헬퍼만 최소 보완함.
- `viewer.html`, `src/viewer.js`
  - 통합 후 안내 페이지 전환 또는 제거함.
- `tests/coinModel.test.mjs`
  - 동전 면 판정과 착지 목표 회전 테스트 보완함.

  - 필요한 테스트 스크립트만 추가함. 새 의존성은 추가하지 않음.

## 8. 구현 순서

1. 모델 레지스트리와 inspect 모드를 프리셋 스튜디오에 통합함.
2. 기존 viewer 모델 목록을 이동함.
3. 단발 주사위 판 시뮬레이션을 추가함.
4. 동전 수직 뒤집기 애니메이션과 결과 표시를 추가함.
5. 기존 프리셋 베이킹·재생 기능 회귀를 확인함.
6. viewer 진입점을 정리함.
7. graphify를 갱신함.

## 10. 완료 기준

- 프리셋 스튜디오 한 페이지에서 모델 보기와 프리셋 작업이 모두 가능함.
- 프로젝트 주사위 종류와 CoinModel을 선택해 볼 수 있음.
- 선택 주사위를 보드에서 단발 투척할 수 있음.
- 동전이 수직 스핀 후 앞면 또는 뒷면으로 바닥에 즉시 밀착함.
- 기존 프리셋 기능과 온라인 게임 코드에 회귀가 없음.
