# 변형 족보 셀 버건디 하이라이트 구현 계획

## 목표

- 변형 증강이 적용된 족보 제목 셀을 현상금 사냥꾼 타깃과 유사한 강조 방식으로 표시함.
- 펄스 강도는 현상금 타깃보다 낮추고 색상은 버건디 계열로 통일함.

## 메커니즘

1. 변형 적용 시 기존 아이콘·족보명 교체 로직을 유지함.
2. 인라인 배경색 대신 변형 전용 CSS 클래스를 제목 셀에 부여함.
3. 셀의 기존 배경과 글자색은 유지하고 버건디 발광 가상 요소를 겹침.
4. 5초 주기로 가상 요소의 불투명도를 0.6~1 사이에서 반복함.

## 변경 파일

- `src/gameRuntime.js`: 변형 족보 제목 셀에 전용 클래스 적용함.
- `src/style.css`: 버건디 하이라이트와 약한 펄스 정의함.

## 검증

- 기존 현상금 타깃 클래스와 충돌하지 않는지 확인함.
- 변형 적용 코드가 인라인 하늘색을 더 이상 사용하지 않는지 확인함.
- 점수표의 기본 `th` 규칙보다 전용 클래스 선택자 우선순위가 높은지 확인함.
- 프로젝트 테스트를 실행함.

## 수정 기록

- 최초 전용 클래스는 `.game-table th`보다 선택자 우선순위가 낮아 배경색과 글자색이 덮였음.
- `#score-table th.modification-target-highlight`로 범위를 명확히 하여 해결함.
- 최종 디자인은 셀 배경과 글자색을 유지하고 버건디 외곽·내부 펄스만 표시함.
- 현상금 사냥꾼의 번짐 크기를 사용하고 발광색만 버건디로 변경함.
- 최종 펄스 주기는 5초이며, 발광 강도는 최대치의 60%에서 100% 사이로 반복함.
- 발광 그림자는 고정하고 전용 가상 요소의 `opacity`를 0.6~1로 보간해 강도 범위를 직접 제어함.
